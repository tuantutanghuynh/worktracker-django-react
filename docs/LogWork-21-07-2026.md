## 1. Môi trường và Cấu trúc Hệ thống (Infrastructure)
- **Framework Lõi:** Kiến trúc Django và Django REST Framework (DRF) hoạt động ổn định.
- **Cơ sở dữ liệu:** PostgreSQL (`worktracker_db`).
- **Cache & Message Broker:** Tích hợp Redis làm lõi lưu trữ hiệu năng cao:
  - Cache truyền thống (Redis DB=1).
  - Celery Broker (Redis DB=2) và Celery Backend (Lưu kết quả vào PostgreSQL qua `django-celery-results`).
  - Django Channels Layer (Redis DB=4) phục vụ WebSockets.
- **Web Servers:** Cấu hình chạy song song Gunicorn/WSGI cho HTTP thường và Daphne/ASGI phục vụ giao tiếp WebSockets (Real-time).
- **Bảo mật kết nối:** Cấu hình `corsheaders` để giao tiếp đa miền.
- **Tài liệu API (API Contract):** Tích hợp `drf-spectacular` tạo trang giao diện Web Swagger (`/api/docs/`).

## 2. Hệ thống Xác thực, Phân quyền & Đội nhóm (Auth & Team)
- **Authentication (NFR-01):** Cấp phát Access/Refresh Token bằng JWT (`rest_framework_simplejwt`).
- **Tối ưu Khóa Tài khoản (NFR-04):** Dùng class `CachedIsActiveJWTAuthentication` để kiểm tra trạng thái hoạt động của tài khoản qua Redis trên mọi Request, đảm bảo khóa tài khoản có hiệu lực tức thì (Immediate Lock).
- **Phân quyền Đa lớp (RBAC):** Xây dựng hàng rào bảo mật 3 lớp chặt chẽ:
  1. `IsActiveAuthenticated`: Xác nhận người dùng hợp lệ.
  2. `IsManagerRole`: Xác nhận chức danh.
  3. `HasPermissionCode`: Kiểm tra quyền hành động cụ thể ở cấp độ chi tiết (Action-level).
- **Seeding Data:** Script `seed_manager_permissions.py` đã cập nhật tự động nạp danh sách 25 quyền cơ bản cho chức danh Manager (bao gồm cả các quyền mới cho Notification và Team).
- **Team Coordinator (P3.6):** Xây dựng bộ API quản lý nhân sự cho Manager, cho phép xem danh sách nhân sự trong dự án và thay đổi/gán phòng ban (Department) cho Employee trực tiếp.

## 3. Module Quản lý Dự án (Projects & Jobs)
- Áp dụng cấu trúc Database chuẩn hóa.
- Hoàn thiện bộ API quản lý Job (tạo, sửa, đổi trạng thái).
- **Scope-level Security:** Xây dựng các hàm lọc `scoped_jobs`, đảm bảo Manager chỉ được phép nhìn thấy và thao tác với các Dự án do chính họ quản lý (`jobs.manager_id`).

## 4. Module Quản lý Công việc (Tasks & Kanban)
- Kết nối mô hình dữ liệu Tasks - Jobs - Users.
- Hoàn thiện bộ API hỗ trợ Kanban Board (Agile):
  - Kéo - thả (Kanban View) sử dụng **Lexicographical String Indexing** (`order_index_manager_service.py`) để tái sắp xếp siêu tốc không cần cập nhật hàng loạt DB.
  - API tạo task, phân công (assignee), thiết lập ưu tiên, hạn chót.
  - State Machine chuyển đổi trạng thái của Task, chặn Employee tự chuyển task sang COMPLETED.
- **Tính năng Người theo dõi (Task Followers):** Hỗ trợ gán nhiều người theo dõi một task.
- **File Đính kèm (P3.5):** Xây dựng luồng tải lên file vật lý (Media Upload), giới hạn dung lượng 20MB, lọc định dạng, lưu trữ file sử dụng chuẩn UUID để tránh trùng lặp Directory Traversal. Đảm bảo tính nhất quán (tự động rollback xóa file đĩa cứng nếu lưu DB thất bại - NFR-21).

## 5. Module Nhật ký Công việc (Timesheets & Time Lock)
- **Ghi nhận giờ làm (LogWork):** API ghi nhận số giờ (kiểu DECIMAL chống sai số).
- **Quy trình Duyệt:** Triển khai API cho Manager: `Approve` (Duyệt) và `Reject` (Từ chối).
- **Quy trình Hậu kiểm:** API `Correct` (Sửa chữa) và `Void` (Vô hiệu hóa) bản ghi lỗi, bảo toàn tính bất biến của lịch sử (không dùng DELETE).
- **Khóa sổ (Time Lock):** Hoàn thiện tính năng khóa kỳ báo cáo theo Tháng/Năm (tầm vực JOB), ngăn chặn mọi thay đổi LogWork sau khi chốt sổ.

## 6. Module Báo cáo và Trích xuất (Reports)
- Xây dựng hệ thống API truy vấn cho **Manager Dashboard**.
- Phân tích hiệu suất bằng biểu đồ nhiệt (Heatmap) giờ làm.
- Tính toán tỷ lệ phần trăm Task trễ hạn, hoàn thành.
- **Tính năng Xuất PDF:** Đã tích hợp `xhtml2pdf` để xuất báo cáo (Task Summary, Timesheet Detail) dưới định dạng PDF chuyên nghiệp, tương thích tốt với môi trường Windows.

## 7. Các Module Dịch vụ Cốt lõi (System Services)
- **Lưu vết Hệ thống (Audit Log):** Chạy ngầm ghi nhận mọi thao tác nhạy cảm (thêm/sửa/xóa logic, đổi trạng thái) kèm snapshot dữ liệu cũ/mới (`old_values`, `new_values`). Bổ sung API (FR-97) cho phép Manager trực tiếp truy vấn, tìm kiếm và lọc lịch sử Audit Logs của mình.
- **Hệ thống Thông báo (Notification Manager):** Hoàn thiện giải pháp thông báo đa kênh toàn diện:
  - **API Quản trị:** Các endpoint để lấy danh sách, lọc chưa đọc/đã đọc, và đánh dấu thông báo.
  - **Email Bất đồng bộ:** Cài đặt Celery Worker (`system.tasks.send_notification_email_task`) thực hiện gửi email nền (background tasks) với cơ chế tự động thử lại (retry) 3 lần nếu có sự cố mạng.
  - **Real-time WebSockets:** Triển khai Consumer `NotificationConsumer`, định tuyến qua `ws/notifications/`, đẩy JSON event xuống ngay lập tức cho client.
